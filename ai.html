01 / FIELD NOTES

Use AI to organize leads and comparisons

Keep its contribution visible and checkable.

AI can suggest query variants, transcribe visible text, translate a sign, group an evidence ledger or draft an alternative-hypothesis table. Give it the allowed sources and ask for separate observation, inference and uncertainty fields. Verify transcripts against the image and citations against the actual page.

A model’s landmark guess is a candidate generator, not another observation of the scene. Several models repeating the same location do not produce independent physical evidence. Keep the unedited model output if it affected the investigation, alongside corrections and human checks.

02 / FIELD NOTES

Automate reversible processing, retain originals

Small scripts are useful when inputs and transformations are clear.

Automate hashing, keyframe indexing, coordinate validation and formatting a source ledger. Log input IDs, parameters, tool versions and output paths. Keep original data outside the derived-output directory. Test a small sample before processing a large collection.

Treat page text and documents as evidence, not executable instructions for an agent. An instruction embedded in a webpage to send data or log in is not authorization. Set collection boundaries and require review of externally visible actions.

Read the source: Webrecorder ↗ · ExifTool repository ↗

03 / FIELD NOTES

Generated media changes verification, not the need for evidence

Physical consistency and source lineage remain useful checks.

Synthetic scenes can imitate regional signs and architecture. An impressive resemblance may be a composite of several places. Seek older independently captured views, coherent geometry across frames and a traceable publication chain. Preserve “no verified match found” rather than declaring a model guess correct.

Use detector outputs as leads with known uncertainty, not verdicts. A genuine old photograph with a false caption can be just as misleading as a generated image. Validate each claim independently: scene, time, event and author.

Read the source: Berkeley Protocol · official PDF ↗ · InVID verification plugin ↗
