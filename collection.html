01 / FIELD NOTES

Search is an experiment with explicit inputs

Translate an information gap into several query families.

Search exact phrases, spelling variants, local-language names and historical names. Narrow by a publisher or file type when useful. Save the query, engine, filters and retrieval time. Search indexing, personalization and regional access affect what appears.

For a public landmark, try its local name with “bridge”, “opening”, “renovation” or the local equivalents. Read the source page instead of citing only a snippet. Search snippets and AI summaries can be truncated or outdated.

"public landmark name" renovation
site:official-publisher.example bridge
"local-language name" filetype:pdf

The .example publisher above is illustrative, not a real target. Keep the broad query if a narrow one returns nothing: lack of indexed results does not establish absence.

02 / FIELD NOTES

Trace the publication chain before counting sources

Ten reposts may contain just one observation.

Find the earliest accessible version, examine quoted links, compare crops and watermarks, and identify which publisher actually observed the scene. The earliest indexed copy is only the earliest you found; it may not be the original. Preserve alternate versions with their own IDs.

Treat sources as independent only for the claim they independently support. An official road map may independently support geometry but say nothing about the time of an event. An article embedding the same video is not another camera.

03 / FIELD NOTES

Collect what the question needs

Distinguish public research from interactions that change the environment.

Public documents, map queries and registration lookups answer many questions without contacting a subject. Login, messages, friend requests and scanning are different operations with different authorization requirements. Plan them separately rather than quietly broadening a collection task.

Prefer small, reproducible queries and official export/API routes. Record pagination, sampling and missing fields. An API or platform limit can cause a partial dataset; a clean graph may still omit most of the network.
