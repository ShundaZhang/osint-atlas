Three deterministic exercises use invented scenes and records. Everything runs in this page: no uploads, external APIs or saved exercise data.

01 / GEO

Eliminate contradictions before adding confidence

Known scene: north–south river, east–west bridge, building on the east bank north of the bridge, T-junction east of the bridge. The source is verified as not mirrored.

Ready — choose an input

The maps are synthetic and north-up. The selected ground check is a teaching input, not a real service call. A visual fit with no independent check remains a plausible candidate; a new ground match cannot erase an existing topology contradiction.

02 / PROVENANCE

Count observation roots for a specific claim

X is one photo of a scene and event. Y is a separate simultaneous camera recording the same event from another angle. The map records site geometry only. Model guesses use X as input.

Ready — choose an input

This exercise counts stipulated roots; it does not authenticate them or calculate truth probabilities. In a real case, independence and what each source supports need their own verification.

03 / COORDINATES

Valid numbers can still describe the wrong place

Normalize a decimal pair and inspect its GeoJSON order. Distance uses the synthetic reference point lat 30°, lon 120° on a spherical Earth of radius 6,371 km.

Ready — choose an input

Try 30, 120 in both orders, then 45, 60: both orders of the latter pass range checks but differ geographically. Unknown reference systems are not converted. Distance is approximate, not a surveying result; no map or location service is queried.
