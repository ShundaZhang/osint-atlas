01 / LEARNING ROUTE

A route from clues to a defensible answer

For engineers and security learners. No specialist GIS background is required; start with the GEO workflow if you already know basic research methods.

01

Build an evidence habit

Foundations → Collection → Media → Evidence. Produce a source ledger distinguishing the original, copies, observations and inferences.

02

Learn to narrow the map

GEO workflow → Visual clues → Maps & OSM. Sketch the scene, generate candidates and record spatial contradictions.

03

Add time, terrain and coordinate discipline

Satellite → Terrain → Time & shadows → Coordinates. Check sensor limits, imagery dates, viewpoint and coordinate order.

04

Publish a reviewable result

Entities → Analysis → AI assistance → Projects / Labs. Keep alternatives, independent evidence and the uncertainty of each claim.

03 / PRACTICE

Keep four useful outputs

The aim is an investigation that can be checked, not a pile of bookmarks.

OBSERVATIONS

A clue sheet

Literal observations, uncertain text, geometry and camera direction.

CANDIDATES

A candidate matrix

Matches, contradictions and missing checks for more than one hypothesis.

PROVENANCE

An evidence ledger

Source IDs, acquisition time, originals, transformations and independent roots.

REPORT

A bounded conclusion

A point, segment, region or unresolved answer with explicit reasons.
